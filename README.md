# Mountain Hut

This repository contains the description and user stories for the Mountain Hut system that is developed as semester project in the Software Engineering II course at Politecnico di Torino

Instructors:

- Marco Torchiano
- Antonio Vetrò
- Riccardo Coppola

## The Mountain Hut project

Goal of the project is to develop a software system capable of supporting the activities of a mountain hut.

First of all read the description of the context in [context.md](context.md).

Then browse the [User Stories](#user-stories).

At any time, using the project issues, you can:

- ask the Product Owner [clarification questions](#clarification-requests) (*Requirement clarification* template)
- ask the Scrum Master process question (*Scrum process question* template)
